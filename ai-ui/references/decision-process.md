# Visual decision process

## 1 Classify before styling
- **Cinematic brand landing**: emotional atmosphere, one main claim, strong media, high typographic contrast, a simple CTA. Can tolerate depth and controlled animation.
- **Operations dashboard**: task first, predictable density, scanlines/labels, actionable rows in first viewport. Large decorative Hero normally harms task completion.
- **Editor / creative tool**: canvas priority, spatial controls, content legibility.
- **Commerce**: product imagery, trust, pricing, availability, clear conversion path.

## 2 Define unique visual thesis
Write one sentence of cause and effect: 'Because [audience/circumstance] needs [job], visually prioritize [specific composition], while avoiding [tempting generic treatment].' If this is interchangeable across any brand, revisit.

## 3 Generate alternatives in exploration mode
Produce 2–3 substantially different image/copy/layout concepts. Vary composition, content hierarchy, interaction entry, not merely hues. Compare with a concrete decision table: legibility, distinctiveness, cost, performance, platform reach. Lock one direction before coding.

## 4 Make details testable
For each screen record: width, min height, max content width, padding formula, primary baseline, heading width and line breaks, imagery crop, foreground/background luminance strategy, material effects exact CSS, component states, reduced motion. Motion with no task contribution requires explicit rationale.

## 5 Asset traceability
For every asset: source, rights/permission status (unknown is allowed), format, alt/role, resolution, loaded verification, fallback, dark/light variation. Do not derive a project quality verdict from an unavailable asset.

## 6 Anti-pattern check
Generic three-card rows, hero empty of content, light gray text on white, arbitrary shadows, identical borders/radii everywhere, hover-only interactions, page-title consuming majority of compact phone screen, pretend stats, form success without backend. These are heuristics, not unconditional bans.

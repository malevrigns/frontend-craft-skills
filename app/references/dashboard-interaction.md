# Dashboard Interaction Contract — v3.1

## 单一状态模型
使用可追踪的 `dateRange`, `metric`, `filters`, `search`, `sort`, `selectedRow`, `dialog`, `sidebar` 状态。图表单位、期间标签、KPI 总量及下载文件必须取自同一数据视图；不能各自设置虚构的硬编码增长值。

## 最小验收路径
1. 切换期间：KPI、趋势轴、图表总计、时间标签一致；切回默认值；Escape 退出弹层后数据不变。
2. 切换指标：图题、轴单位、图线、tooltip 和总计一起更新，不能只改变按钮样式。
3. 表格搜索 + 筛选：组合筛选、清空条件、无结果反馈，交易字段不丢失；移动端关键信息全部可访问。
4. 导出：文件有正确扩展名、UTF-8/BOM 或其他可靠编码、字段与当前筛选或明确的范围一致；给出下载完成反馈而不是宣称云端已保存。
5. 移动菜单：可键盘到达，打开时焦点进入菜单，Tab 不落到遮罩背后的页面，Escape/遮罩/选中导航项能关闭，关闭后恢复焦点。
6. 异常：数据为空、接口失败、网络超时、长标签、重复点击、窗口尺寸变化；这些状态必须有文字而不是只靠颜色区分。

## 禁止项
- 非实时的本地示例不能显示“已实时同步”或“你的商业数据”。
- 图表有“上一期/目标线”图例但没有对应数据系列。
- 仅检测 `scrollWidth` 为零就宣称移动布局通过。
- 显示不可点击的菜单或图标，却用 hover 态伪装成操作入口。

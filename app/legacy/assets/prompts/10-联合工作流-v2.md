# 两 Skill 联合任务提示词 v2.0

请按 ai-ui → app 的次序输出：
1. BRIEF：目标用户、具体任务、平台、3 条假设及非目标。
2. DESIGN：视觉原则、token 语义、信息架构、窄屏/宽屏布局、组件各状态与例外。
3. INTERACTION：逐条写事件→状态→反馈→撤销/失败→键盘替代路线，每屏不超过三个装饰性交互。
4. PROTOTYPE：可运行、可编辑的组件化源码，不以静态图代替功能。
5. QA：以通过/失败/未执行列出主路径、焦点与键盘、320/390/768/1440、暗色与减少动态效果、真机适配。
禁止把 Web DOM 组件称作可直接运行于 Expo 原生。若无产品信息，则写显式假设并以样例产品验证规则。

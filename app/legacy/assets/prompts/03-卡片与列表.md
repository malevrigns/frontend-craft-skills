# 卡片与列表
在 {{列表}} 实现 {{效果}}：
- 左滑删除（swipe）：方向锁 6px 判横竖；阻尼右拉 0.3；超过 40% 宽或速度 > .5px/ms 直接删，否则吸附 -88px 露出删除或回弹；删除时高度收起 + 撤销条。
- 列表切网格（layout）：FLIP——记录旧位置 → 切 class → 反向 transform → 460ms 放开。
- 筛选三曲线（filter）：离开项 ease-in 原地缩小淡出 180ms；留下项 FLIP 移位；新来项回弹放大淡入，错峰 40ms。
- 卡片翻面（flip）：perspective 900px + preserve-3d + backface-visibility:hidden，700ms 回弹。
- 扇形展开（fan）：transform-origin 50% 150%，每张旋转 (i-1.5)*14°。
- 骨架屏：骨架尺寸 = 真实内容，扫光 1.3s。入场错峰：标题→内容→按钮，50ms 间隔 + 弹性上滑。
- 券卡厚度（coupon）：跟手 3D 倾斜 ±9°，高光随指针移动，内部图案比卡片多移动一点形成视差。
- 长按拖拽排序：长按 260ms 拿起；被拖卡关过渡，其他卡开过渡让位；只改数组顺序。

# 转场与滚动
- 共享元素（shared）：FLIP——大图 transition:none 钉在小图位置，双 rAF 后放开过渡到目标位置，关闭原路返回。
- 页面推入（push）：新页从右推入带左侧阴影，旧页 scale(.94) + brightness(.6)。
- 大标题折叠 / sticky header（largetitle）：p = min(scrollTop/46, 1)，缩放、位移、透明度、分割线都挂在 p 上，不写成多段动画。
- 弹性 Tab 指示条（tabs）：关键帧 45% 处宽度 = 覆盖新旧两个 Tab，前沿先到后沿再跟上。
- 分类联动滚动（category）：右侧滚动高亮左侧；点左侧平滑滚右侧，滚动期间锁定 600ms 避免互相触发。
- 抛物线飞入（fly）：外层 X 轴 linear，内层 Y 轴先上抛再下落，落点角标回弹 +1。
- 圆形扩散：见 skill 精致交互六件套 circle-tabs。

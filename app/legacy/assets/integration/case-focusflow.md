# 联合实践案例：序刻 / FocusFlow（假设性产品）

**案例定位**：为有多任务切换负担的个人提供一个移动/桌面通用的“今天要做什么”工作台。此为设计演示，不代表已经进行市场验证。

**核心任务**：添加任务 → 完成任务 → 今日进度同步变化 → 错误可撤销；另可开启专注计时。

**审美策略（ai-ui）**：Swiss/editorial 混合但只取一个主调，柔和纸面背景、深墨文字、克制青绿强调、数字大字、网格对齐，避免全屏玻璃与无意义装饰。

**交互（app）**：1. 完成任务后计数与进度联动 + 撤销；2. 新建任务弹层含校验、Escape、恢复焦点；3. 专注计时的明确开始/暂停/重置状态。

**平台**：Web/Tauri 复用 DOM 视图；Expo Native 重写任务卡片与弹层，状态协议保持不变。桌面侧边栏、手机底部导航，主任务放在主屏。

**验收案例**：添加一条任务可见、勾选后计数准确、撤销恢复旧状态、刷新后保留状态、键盘能完成相同动作，390px 不横向溢出。

**案例实现**：详见交付目录的 `focusflow-demo/index.html`。项目演示不依赖云服务，使用浏览器本地存储。

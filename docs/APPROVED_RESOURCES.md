# APPROVED_RESOURCES · 用户认可的资源库（只存 URL）

用途：当用户对某次产出的组件 / 设计 / 动效表示「好看 / 认可 / 满意」时，把对应外部资源的 URL 记到这里，形成可迭代的个人审美资源池。**只记 URL 与一句备注，不拷代码、不存大段内容。**

## 使用规则
1. **记录**：用户点赞某效果时，把来源 URL + 类型（组件库 / 设计库 / 动效库 / 模板）+ 一句备注追加到对应分类。
2. **先搜再选**：每次实现前，先在本文件与外部检索可用资源；当同类有 ≥2 个可选资源时，**先列出候选（名称 + URL + 一句差异）询问用户选哪个**，再执行；不要替用户默认决定。
3. **单一来源**：同类只有一个已认可资源时可直接复用，但仍需在交付的复用清单中写明 URL。
4. **迭代**：用户推翻某个旧偏好时，把对应条目标注 `(deprecated)` 并补新选择。
